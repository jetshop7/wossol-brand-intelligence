# WOSSOL PRODUCT -> BRAND INTELLIGENCE - METHODOLOGY CHANGELOG

## V1.2 - Connected Merchant Value & Decision-Effort Upgrade

**Change ID:** METH-2026-09-26-001  
**Date:** 2026-09-26  
**Previous Version:** 1.1  
**New Version:** 1.2  
**Origin:** Cross-section review of Orders provenance, Messaging continuity, Analytics/Decision Center, Market Center, Inventory/Finance connectivity, and under-extracted merchant value.  
**Status:** Applied; retroactive migration required.

### Problem discovered

V1.1 was strong at product truth, evidence, control, transparency, feature interaction, and claim safety, but a technically correct section audit could still under-extract the merchant value created by:
- work the merchant no longer has to perform;
- tools/processes Wossol consolidates;
- workflow friction and context switching removed;
- source/provenance preserved across systems;
- cross-domain chains whose value appears only downstream;
- reconciliation and cognitive/decision work removed;
- the distinction between Merchant, Market, Decision, and Learning Intelligence.

This created a **section-island failure mode**: a section could pass while missing a major compound advantage.

### New mandatory lenses

V1.2 adds:
1. Merchant Job-to-be-Done Removal
2. Tool / System Consolidation
3. Friction and Step-Count
4. Context Continuity
5. Provenance-to-Outcome Trace
6. Operational Truth → Economic Truth → Decision Value
7. Intelligence Layer Model
8. Decision Effort Reduction
9. Section-Island Failure Mode
10. Mandatory Second-Pass Value Synthesis
11. Retroactive Migration Rule

### Expected improvement

Audits must now discover not only **what Wossol built**, but:
**what work disappears → what truth is preserved → what domains connect → what outcome becomes knowable → what decision becomes easier → what value compounds over time.**

### Affected previous sections

All previously audited sections are potentially affected because V1.2 changes the value-extraction and cross-domain completeness standard. Highest-priority re-audits are Orders, Messaging/Order Capture, Analytics/Decision Center, Market Center, Inventory, Finance, Advertising, and Integrations/Commerce Channels.

**Retroactive Review Required:** Yes
