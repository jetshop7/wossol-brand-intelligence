# Merchant Evidence Codebook

## Evidence unit

Code a concrete event, behavior, workaround, consequence or counterexample—not a generic statement of preference.

## Core codes

### RB — Reconstruction Burden
- RB-SEARCH: finding object/context across tools
- RB-REENTRY: repeated data entry
- RB-HANDOFF: context lost between people/providers
- RB-CHASE: asking support/provider/person for missing context
- RB-ERROR: error caused by reconstruction

### RC — Reconciliation
- RC-OPSFIN: operational vs financial
- RC-PAYOUT: payout/remittance
- RC-STOCK: stock/inventory
- RC-COST: cost/profit
- RC-SOURCE: acquisition/source/performance
- RC-MANUAL: spreadsheet/manual merge/calculation

### CT — Control
- CT-VIEW: visibility only
- CT-CONFIG: configure policy
- CT-APPROVE: approve/confirm
- CT-HOLD: pause/hold
- CT-CORRECT: correct data/state
- CT-ASSIGN: assign ownership/work
- CT-OVERRIDE: consequential override
- CT-DELEGATE: prefers work fully delegated

### PV — Provenance / Verification
- PV-SOURCE: needs origin/source
- PV-HISTORY: needs history/previous value
- PV-ACTOR: needs who changed/acted
- PV-PROVIDER: needs provider evidence
- PV-MONEY: evidence required for money/profit
- PV-UNKNOWN: values explicit unknown/partial state
- PV-NOISE: provenance/detail considered excessive

### DP — Decision Preparation
- DP-EXPORT
- DP-MERGE
- DP-CALCULATE
- DP-COMPARE
- DP-EXPLAIN
- DP-RECOMMEND
- DP-AUTO: accepts autonomous action
- DP-HUMAN: requires human judgment

### CO — Consequence
- CO-TIME
- CO-MONEY
- CO-CUSTOMER
- CO-STOCK
- CO-DELAY
- CO-RISK
- CO-MENTALLOAD

### ALT — Alternative / Workaround
- ALT-SHEET
- ALT-CHAT
- ALT-PROVIDER
- ALT-EMPLOYEE
- ALT-AGENCY
- ALT-TOOL
- ALT-NONE

### SEG — Segment signal
- SEG-MANAGED
- SEG-INHOUSE
- SEG-HYBRID
- SEG-FOUNDER
- SEG-TEAM
- SEG-MULTIMARKET

## Evidence strength

- E3: recent concrete event with workflow + consequence
- E2: repeated behavior with some concrete detail
- E1: stated preference/opinion only
- C: counterevidence to hypothesis

Prefer E3/E2 when evaluating territories.
