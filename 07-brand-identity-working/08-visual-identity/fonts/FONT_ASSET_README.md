# Font assets used by the V0.2 visual proof

These two variable font files are included only to make the V0.2 identity specimens reproducible and render exact, locally loaded families. Both OFL 1.1 notices are preserved beside their fonts. The fonts are not sold separately.

| Family | File | Version/source information | License |
|---|---|---|---|
| Inter | `Inter-4.1-Variable.ttf` | Google Fonts package metadata identifies upstream Inter 4.1; Google Fonts repository snapshot `e7db6ca603fd4862010383ff17ffd6cc4ffac1c0`; variable `opsz,wght` axes | [Inter-OFL.txt](Inter-OFL.txt) |
| Noto Sans Arabic | `NotoSansArabic-2.012-Variable.ttf` | Upstream Noto Arabic v2.012; Google Fonts repository snapshot `e7db6ca603fd4862010383ff17ffd6cc4ffac1c0`; variable `wdth,wght` axes | [NotoSansArabic-OFL.txt](NotoSansArabic-OFL.txt) |

Official source: [Google Fonts Inter package](https://github.com/google/fonts/tree/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/inter) and [Noto Sans Arabic package](https://github.com/google/fonts/tree/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl/notosansarabic). The SVG boards use local relative `@font-face` references to these packaged TTFs; do not replace them with system fallbacks when reproducing the typography verification. Preserve the OFL notices if redistributing either font file. This package is a production specimen, not a legal review of a future hosted deployment or a substitute for testing browser font packaging.
