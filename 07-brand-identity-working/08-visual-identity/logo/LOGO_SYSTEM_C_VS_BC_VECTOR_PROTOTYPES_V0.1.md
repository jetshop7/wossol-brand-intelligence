# Wossol — C vs B/C Vector Logo System Prototypes V0.1
Date: 2026-10-24
Status: UNDER_REVIEW — no logo approved
Version: 0.1

## Objective / Scope
Construct two editable monochrome vector symbol+wordmark systems, and test symbol export at 16, 24, 32, 64 and 128px, rather than repeating wordmark-only mockups.

## Sources / Evidence
Brand Identity Master Instructions V2.0; LOGO_SYSTEM_DIRECTION_C_VS_BC_V0.1.md; R2 wordmark studies and user feedback. Four actual SVG sources archived alongside this report. Local comparison PNG and size exports delivered separately.

## Findings / Analysis
C: angular S geometry remains the stronger typographic direction, but the new octagonal frame symbol reads as generic technical apparatus. B/C: soft lettering is readable but less differentiated; circular symbol resembles a G or UI control. These are actual SVG path/stroke constructions, not proof of ownability, recognition or legal clearance. Pixel exports were performed but not tested with merchants. No production/dashboard integration tested. Both symbol designs are weak and should not be adopted.

## Recommendation
Preserve C as leading TYPOGRAPHIC research direction and B/C as legibility reference. Reject BOTH new symbol proposals. Reframe symbol design around verified business pillars and a distinctive repeatable graphic system rather than a post-hoc arbitrary icon. Do not select a logo or palette yet.

## Decisions
No user design approval; exploratory studies only.

## Open Questions
Can a differentiated app icon emerge from the graphic grammar? Can the angular S be read reliably in merchant-facing usage?

## Next Actions
Compare C against original C/B-C references at small sizes; build one strategy-led graphic device; test symbol-only and wordmark-only in actual-size dashboard/social contexts.
