# Wossol — R2 Wordmark Letterform Craft V0.2
Date: 2026-10-24
Status: UNDER_REVIEW
Objective: Refine the leading R2 wordmark route through explicit vector paths for all letters, rather than modify a font with a decorative W.

## Editable source
- R2_A_CUSTOM_WORDMARK_V0.2.svg: more open W and lighter stroke.
- R2_B_CUSTOM_WORDMARK_V0.2.svg: tighter W and heavier stroke.
These source files are archived in the same GitHub directory. PNG exports at 160, 240, 320 and 440 pixels plus comparison.png are conversation-local downloadable files.

## Design findings
- Both versions draw W/o/s/s/o/l as paths. Shared o and s geometries promote internal consistency.
- R2-A feels relatively open; R2-B slightly more solid, but the two differ mostly in W geometry and stroke width.
- The s/s pair is legible in desktop-size comparisons but the rhythm and terminal behavior still resemble generic rounded technical wordmarks.
- Neither is proven distinctive, memorable or legally clear. This is a craft desk test, not an audience recognition test.

## Assistant recommendation
R2-B is a provisional craft challenger, not an approved logo. The next meaningful design iteration should substantially redesign letter anatomy, W/o connection, s/s rhythm and optical spacing rather than create more near-identical weight variants. Do not imply the exported full wordmark at small widths is an app icon.
