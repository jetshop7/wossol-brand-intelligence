# Wossol — Original Arabic Lettering Construction V0.9
Date: 2026-10-25
Status: UNDER_REVIEW — REFINE, not approved

## Sources and continuity
Read current governance V2, project entrypoint, README, PROJECT_STATUS, PROJECT_INDEX, DECISION_LOG, V0.8 exact 36px icon QA, original C vector wordmark and prior Arabic B live-font reference. V0.8 explicitly rejected treating mere font outlining as original lettering.

## Design objective
Construct genuinely new Arabic letterform paths for «وصول» rather than converting a commercial/open-source font to outlines. Preserve right-to-left reading order and optical compatibility with C Latin master; no further S/W icon loops.

## Executed
Designed original, manually specified cubic Bézier paths with stroke widths and joins for two waw forms, a sad + waw connection and terminal lam. Source SVG contains independent editable paths, not live-font glyphs or font outlines. Rendered using Inkscape; created 1500x1100 comparison board against original unchanged C wordmark, standalone Arabic PNG, and 160/240/400px Arabic exports. Packaged editable SVG and PNG in conversation ZIP WOSSOL_CUSTOM_ARABIC_LETTERING_V09.zip. Source SVG archived in repository alongside this report.

## Quality assessment
- Manual geometry is original vector construction, not mere font outlining. However originality of path construction does NOT establish trademark ownability.
- Arabic spelling is intended as وصول in RTL sequence (rightmost waw, sad+waw connection, leftmost lam), but desk rendering shows weak sad letter differentiation, exaggerated curvature, uneven join rhythm and uncertain native readability. The large bowl shapes lack optical kinship with C's sharp S.
- The comparison board is a visual study, not a native Arabic reader evaluation, legal clearance, browser implementation or approved Arabic master.
- Small-width PNG exports exist but do not establish legibility with real merchants. No production integration.

## Professional recommendation
REFINE / DO NOT APPROVE. Keep original C Latin as provisional lead. Redesign sad and waw/lam spacing based on correct Arabic joining rules, then test native reading and optical weight. If original hand construction cannot meet professional Arabic lettering quality, use a properly licensed high-quality Arabic typeface with genuinely purposeful customizations, documenting font provenance. Do not ship V0.9 as logo. No new icon work until bilingual foundation improves.
