# Wossol C vs B Bilingual Lockup Comparison V0.1
Date: 2026-10-25
Status: UNDER_REVIEW

## Objective
Compare original archived R2-C and R2-B Latin SVG vectors with the same Arabic وصول text in horizontal, stacked, and compact mobile arrangements.

## Work completed
Created a 1500x1170 PNG comparison and editable SVG in the conversation. Arabic uses a provisional Noto Sans Arabic Bold font, not a designed Arabic logo. The Latin letter paths come from the original R2-C V0.3 and R2-B V0.2 SVG sources. These are schematic compositions, not production interface captures. No merchant interviews or legibility measurements were conducted.

## Findings
C has a more characteristic angular Latin construction but creates greater contrast with the provisional rounded Arabic font. B pairs more gently but remains generic. Stacked bilingual arrangements are too tall for compact headers. A Latin-only compact header is a provisional layout option, not a brand policy.

## Recommendation
REFINE C as leading unapproved Latin direction; retain B as legibility benchmark. Do not approve either lockup or the provisional Arabic typography. Next: create two genuinely distinct Arabic wordmark treatments, evaluate with C, and prepare controlled merchant reading tests. No logo, typeface, icon, or palette approved.
