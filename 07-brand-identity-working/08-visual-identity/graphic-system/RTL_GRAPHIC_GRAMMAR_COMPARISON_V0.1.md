# Wossol RTL graphic grammar comparison V0.1
Date: 2026-10-25
Status: UNDER_REVIEW
Version: 0.1

## Objective
Compare three monochrome, hypothetical RTL-ready interface graphic devices as alternatives to repeated S decoration, and test distinctiveness before any brand system adoption.

## Sources / evidence
Brand Identity Master Instructions V2.0; Project Entrypoint; PROJECT_STATUS and INDEX; LOGO_SYSTEM_C_VS_BC_VECTOR_PROTOTYPES_V0.1.md. Locally produced SVG and PNG: WOSSOL_RTL_GRAMMAR_COMPARISON.svg/png, supplied in conversation, not necessarily in repository.

## Findings
01 Directional rail: helpful hierarchy, too familiar (timeline/stepper).
02 Offset cut: visually pronounced but heavy and likely to obstruct merchant data.
03 Open corner: quieter and more scalable, but still generic; retain only as an optional functional UI layout hypothesis.
These are schematic UI cards with Latin placeholder labels, not genuine Arabic shaping, production dashboard integration, merchant testing, or proof of trademark/visual ownability.

## Recommendation
Reject all three as official distinctive brand devices. Do not mistake UI affordances for brand identity. Preserve C as unapproved leading typographic direction and B/C as readability control. Next verify real dashboard constraints, bilingual typographic pairing, and consider a wordmark-first system without a forced symbol.

## Decisions
No user approval or final visual decision.

Which real dashboard views offer identity expression? Can an original no-logo visual grammar support RTL and Latin consistently? Is a standalone icon essential for app/favicon?
