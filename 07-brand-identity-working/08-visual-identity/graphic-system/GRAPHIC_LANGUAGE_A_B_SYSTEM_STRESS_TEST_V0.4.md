Repeating vertical blocks in three grayscale tones. Functional strength: suggests repeatability and operations. Identity weakness: generic chart/data pattern, mechanical repetition, consumes attention around important merchant data. REJECT as signature. Do not reuse as decorative motif.

## Recommendation — REFRAME
Both are weak brand signatures. The earlier rejected UI devices and icons show a repeated failure mode: turning generic operational UI conventions into brand identity. Stop drawing abstract symbols, rails or data blocks without a deeper concept. Next build one coherent **wordmark-first identity system** using C as typographic research lead, meaningful copy, editorial rhythm, bilingual typographic hierarchy and restrained functional UI conventions. Then test whether it can stand without a symbol and identify exact unavoidable icon-only contexts. If it cannot, create a truly independent icon brief grounded in those use cases, not in invented metaphors. No final design approved.
