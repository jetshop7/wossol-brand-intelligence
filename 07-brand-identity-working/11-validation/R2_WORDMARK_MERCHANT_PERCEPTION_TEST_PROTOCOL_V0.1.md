## Objective
Test R2-B rounded vs R2-C angular Wossol wordmarks for reading, merchant-relevant personality and delayed recall before designing further iterations. This is a protocol, NOT completed research.

## Hypotheses (unverified)
H1: R2-B is read more accurately and feels more approachable.
H2: R2-C seems more distinctive but more industrial/technology-centric.
H3: Neither is sufficiently distinctive for approval.

## Recruitment
Aim for 6-10 actual merchants in the intended primary market as a directional qualitative pilot, with a mix of early-stage and established operations. Do not claim representativeness or statistical significance. If possible include Arabic-first and Latin-comfortable merchants; record language background non-identifiably. Obtain consent; do not publish personally identifying information.

## Stimulus control
Use archived SVG sources exported in black on white at equal visual height, not unequal artboard widths. Randomize A/B presentation order across participants. Show each mark separately at realistic digital-header size, then together. Do not mention designer preference or meaning before asking questions. Use a baseline ordinary sans-serif Wossol rendering only if a fair comparator can be prepared; mark baseline separately.

## Interview script
1. 3-second first exposure to a single logo. Hide. Ask: What exact name did you read? Record verbatim, no correction.
2. Show again. Ask: What type of company does this seem to be? Open-ended first.
3. Ask for 1-3 descriptive adjectives, without supplying options.
4. Repeat with the other logo, alternating order.
5. Show both. Ask: Which feels more trustworthy and approachable for a platform serving merchants, and why? Which feels easier to read? Which feels more memorable?
6. After 2-3 minutes of unrelated discussion, ask participant to write the name and describe any letter or shape they recall.
7. Ask whether either feels similar to another brand they know; request name if volunteered, but do not imply direct collision.

## Evaluation / decision gates
- Exact reading: count unprompted correct Wossol responses per candidate; retain individual errors and ss confusion.
- Personality: code open-ended descriptors as approachable, capable, reliable, industrial, cold, generic, other; preserve verbatim evidence.
- Recall: delayed spelling and specific features; no invented numerical score.
- If B wins reading but loses distinctiveness, do not auto-approve; redesign the letter system with one meaningful differentiated construction.
- If C is read poorly or feels inappropriate, stop C.
- If both underperform, commission a different typographic strategy; do not endlessly create weight variants.
- Never claim legal availability or trademark distinctiveness from this pilot.
